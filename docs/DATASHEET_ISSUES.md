# Datasheet issues

Problems in the manufacturers' documents, or conflicts between a document and an independent source (a vendor's own driver, a standard), found while checking the models. Generated by `virtulab datasheet --issues`; the entries live in `virtulab/datasheets/*.yml` as the `issue` of a row. Each says what the model does about it.

## Analog Devices ADXL345 3-axis accelerometer

- **Output data rate** (adxl345-ds Table 16, p. 14): Only Rev. 0 of this datasheet could be downloaded; the Rev. G the model used to name was not obtained. Facts here are cited to Rev. 0.

## Generic Modbus RTU temperature and humidity transmitter

- **Baud rate and line settings** (modbus-serial §2.5.1, p. 12): The specification requires 19200 bit/s, even parity as the default. The catalog and sample driver use 9600 8N1, which real transmitters may differ on. The model checks neither baud rate nor parity, so a driver with the wrong line settings still passes.

## Sensirion SHT31 temperature and humidity sensor

- **Measurement time** (sht3x-ds §2, p. 7): Two tables: 2.4 to 5.5 V gives 4, 6 and 15 ms maximum (Table 4), 2.15 to 2.4 V gives 4.5, 6.5 and 15.5 ms (Table 5). The model uses Table 5, the worst case.
